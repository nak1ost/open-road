# Open Road — гонка с открытым миром (Unity 6)

Остров 8×8 км, 33 машины 7 марок (Changan, Lada, Mercedes-Benz, BMW, Lexus, Lamborghini, Audi), бесплатный тюнинг, гонки по маршрутам и игра по Wi-Fi (LAN). Платформы: Android (APK) и iOS (IPA для SideStore).

## Что есть в игре

- **Карта 8×8 км.** Остров с горами на северо-западе, рекой и морем вокруг. 8 вымышленных городов (Приморск, Лесное, Солнечный, Восток, Заречье, Каменка, Северск, Центральный) с улицами и домами. Между городами 11 трасс, по краям острова лес. Карта генерируется в игре из одного зерна, поэтому у всех игроков она одинаковая. Подгружаются только участки 1×1 км вокруг машины.
- **Свободная езда** по всему острову. Если упал в море или перевернулся — кнопка «Сброс» ставит машину на ближайшую дорогу.
- **Гонки с ботами (0–7 соперников):**
  - кольца по улицам каждого города (3 круга);
  - спринты по каждой трассе между городами;
  - «Большое кольцо острова».
  Есть чекпоинты-арки, обратный отсчёт, место, круг, время и результаты.
- **Гараж:** всё бесплатно. Покраска (5 типов), тонировка (3 зоны), койловеры (клиренс, жёсткость, амортизаторы, развал, вылет), диски, шины, двигатель, главная пара, тормоза, спойлер, неон, цвет фар. Тюнинг меняет физику по-настоящему.
- **Игра по Wi-Fi (LAN):**
  - «Создать игру» на одном телефоне, «Найти игры» на остальных; можно подключиться и по IP хоста;
  - свободная езда вместе;
  - хост запускает гонку для всех по любому маршруту;
  - видны машины и тюнинг других игроков, их имена и точки на миникарте.
  Интернет не нужен, только общая Wi-Fi сеть или точка доступа с телефона.

## Управление

На телефоне — сенсорные кнопки: руль, газ, тормоз, ручник, сброс, камера, гараж, меню.

На ПК (для проверки в редакторе):

| Клавиша | Действие |
|---|---|
| W / S | газ / тормоз, при остановке — задний ход |
| A / D | руль |
| Пробел | ручник |
| Q / E | сменить машину |
| R | на дорогу / на колёса |
| C | камера |
| G | гараж |
| Esc | меню |

## Как собрать

### Android APK (на этом ПК)
1. Unity Hub → войти в аккаунт Unity (бесплатная лицензия Personal).
2. Собрать из командной строки:
   ```
   "D:\Unity\Editors\6000.3.28f1\Editor\Unity.exe" -batchmode -quit -projectPath "D:\game" -executeMethod RaceGame.Editor.BuildScript.BuildAndroid -logFile build-android.log
   ```
   или в редакторе: меню **Tools → Game → Build → Android APK**.
3. Готовый файл: `Builds/Android/OpenRoad.apk`. Скинь его на телефон и установи (разреши «установку из неизвестных источников»).

### iOS IPA (для SideStore)
IPA собирается только на Mac, поэтому используется бесплатная облачная сборка GitHub Actions (`.github/workflows/build.yml`):
1. Загрузи проект в свой приватный репозиторий на GitHub.
2. В репозитории: Settings → Secrets and variables → Actions → добавь `UNITY_EMAIL`, `UNITY_PASSWORD`, `UNITY_LICENSE` (содержимое файла `C:\ProgramData\Unity\Unity_lic.ulf`).
3. Actions → **Build** → Run workflow. Через 20–40 минут внизу страницы появятся `OpenRoad-iOS-IPA-SideStore` и `OpenRoad-Android-APK`.
4. Открой IPA в SideStore на iPhone. SideStore подпишет его твоим Apple ID; приложение нужно обновлять в SideStore раз в 7 дней.

## Каталог машин

`Assets/Resources/Data/cars.json`: размеры, масса, мощность, момент, привод, передачи, максималка. Новая модель добавляется одной строкой в этот файл. Настоящая 3D-модель подключается как префаб `Assets/Resources/CarModels/<id>.prefab`. В названиях объектов модели: кузов — со словом `body`, стёкла — со словами `glass` / `window` + `front` / `rear`.

## Тесты

Window → General → Test Runner → EditMode → Run All. Проверяются каталог, физика двигателя, тюнинг, сохранение, карта (детерминизм, размеры, уклоны дорог) и сетевой протокол.
